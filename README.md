Dogs Mine Game

A single-file HTML minesweeper-style game. The aim of the game is to find diamonds. Mines reduce your dog count by 25% instead of ending the run, and you get more dogs as a reward.

Features
1. *Risk vs Reward*: Pick how many dogs are on the board. More dogs = higher multiplier per diamond.
2. *Mine Penalty*: Hitting a mine removes 25% of remaining dogs from the board, lowering risk going forward.
3. *Diamond Boost*: Each diamond increases your multiplier. Cash out before you run out of safe tiles.
4. *Dog Reward*: Finding diamonds gives you more dogs, increasing potential rewards.
5. *AI Powered Assistant*: Built-in assistant on the site to help with gameplay questions.
6. *No Build Tools*: Pure HTML/CSS/JS. Open `index.html` and play.
7. *Lightweight*: Works offline, mobile-friendly, no dependencies.

How to Play
1. *Set your bet* and choose the starting number of dogs.
2. *Click tiles* to reveal diamonds or mines.
3. *Diamond*: Multiplier goes up and you get more dogs as a reward. Keep going or cash out.
4. *Mine*: 25% of remaining dogs are removed. Risk drops, multiplier stays.
5. *Cash out* anytime to lock in winnings.

Tech Stack
- *HTML5*: Game board and layout
- *CSS3*: Styling, animations, responsive grid
- *Vanilla JavaScript*: Game logic, RNG, UI updates
- *No build step*: Runs directly in the browser
